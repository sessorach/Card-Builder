Where will TTS load the images from?
Where is it?

Windows: C:\Users\you\Documents\My Games\Tabletop Simulator\Saves\Saved Objects

Mac: /Users/you/Library/Tabletop Simulator/Saves/Saved Objects

Linux: /home/you/.local/share/Tabletop Simulator/Saves/Saved Objects

After downloading, upload the files from images/ to this address.

Spreadsheet columns

The first row holds column names. Only name is needed; everything else is optional.

nameCard name.
countCopies in the deck (default 1; 0 leaves the card out).
deckWhich deck the card belongs to. Each deck becomes its own TTS object.
artOptional. Images match cards by name; use this to pick a different file, e.g. shared-art.png.
costShown in a badge in the corner (Street shows it as $3).
type, subtypeType line, e.g. “Creature — Imp”.
tagsStreet: comma-separated tags after the type, e.g. Leader, Hustler.
textRules text. Supports **bold**, *italic*, {icon} and line breaks.
flavorItalic flavor text under the rules.
statsDefault, Full Art, Text Only: one badge, e.g. 3 / 2.
strengf, helf, stealStreet: the three Thug stats, each in its own box. Leave them empty on other cards and the rules box grows to fill the space.
colorOptional card color: a name (crimson) or hex (#3b5b7a). Street colors cards by type unless this is set.
layoutOverride the layout for this card: .

Icons: {fire} in text draws an uploaded image named fire.png or icon-fire.png. Without one, it draws a ringed letter.
