Where will TTS load the images from?
Where is it?

Windows: C:\Users\you\Documents\My Games\Tabletop Simulator\Saves\Saved Objects

Mac: /Users/you/Library/Tabletop Simulator/Saves/Saved Objects

Linux: /home/you/.local/share/Tabletop Simulator/Saves/Saved Objects

After downloading, upload the files from images/ to this address.

How to load your deck into TTS
  1. Download the TTS deck with the button above.
  2. Unzip it. Inside is a folder called Card Builder.
  3. Move the Card Builder folder into your Saved Objects folder: It has to be that exact folder, because the deck looks for its card images there.
  4. Open TTS and start a game (Singleplayer is fine for a first look).
  5. Click Objects in the top menu, then Saved Objects → Card Builder, and click a deck to put it on the table.

Only you will see these cards. To play online, choose A website above.

  1. Download the TTS deck with the button above.
  2. Unzip it. Inside the Card Builder folder are your decks and an images folder.
  3. Upload the files inside images to Each file should open in a browser at that address followed by its file name.
  4. Move the Card Builder folder into your TTS Saved Objects folder. Windows: Documents\My Games\Tabletop Simulator\Saves\Saved Objects
    Mac: ~/Library/Tabletop Simulator/Saves/Saved Objects
  5. Open TTS, click Objects in the top menu, then Saved Objects → Card Builder, and click a deck to put it on the table.

Everyone in the game loads the images from your website, so all players see the cards. Only the person putting the deck on the table needs the Saved Objects files.

If something goes wrong

  • The deck isn't in Saved Objects: make sure Card Builder sits directly inside Saved Objects. Unzipping sometimes adds an extra folder around it; if so, move the inner one.
  • Cards are blank or show an image error: TTS can't find the pictures. The deck looks for them in exactly this folder, so check they're there: Check that the images open in your browser at the address you entered.
  • Changed some cards? Download again and replace the old Card Builder folder, and upload the new images. TTS picks up the changes because the image names are new each time.

Spreadsheet columns

The first row holds column names. Only name is needed; everything else is optional.

nameCard name.
countCopies in the deck (default 1; 0 leaves the card out).
deckWhich deck the card belongs to. Each deck becomes its own TTS object.
artOptional. Images match cards by name; use this to pick a different file, e.g. shared-art.png.
costShown in a badge in the corner (Street shows it as $3).
type, subtypeType line, e.g. “Creature — Imp”.
tagsStreet: tags shown after the type, all in one cell separated by commas, e.g. Crew, Leader.
textRules text. Supports **bold**, *italic*, {icon} and line breaks.
flavorItalic flavor text under the rules.
statsDefault, Full Art, Text Only: one badge, e.g. 3 / 2.
strengf, helf, stealStreet: the three Thug stats, each in its own box. Leave them empty on other cards and the rules box grows to fill the space.
colorOptional card color: a name (crimson) or hex (#3b5b7a). Street colors cards by type unless this is set.
layoutOverride the layout for this card: .

Icons: {fire} in text draws an uploaded image named fire.png or icon-fire.png. Without one, it draws a ringed letter.
