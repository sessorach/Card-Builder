Tabletop Simulator deck

You'll download a folder of ready-made decks, one for each deck in your spreadsheet, with the right number of copies of every card. You put that folder where TTS keeps its saved objects, and the decks show up in TTS's Objects menu.

First: where should TTS get the card pictures from?

  1. Download the pictures to upload

    This gives you a ZIP with a few pictures: each one holds all of a deck's cards on one big sheet, plus one for the card back. Unzip it somewhere easy to find, like your Downloads folder.

  2. Upload them to your Steam Cloud, inside TTS

    • Open Tabletop Simulator and start any game. Singleplayer is fine.
    • In the menu bar along the top of the screen, click Upload, then Cloud Manager.
    • Click the folder icon to the left of the Cloud Manager's search bar, and pick one of the pictures you unzipped.
    • Do the same for each of the other pictures.

    Your Steam Cloud is free storage that comes with your Steam account. Pictures stay there until you delete them.

  3. Copy each picture's link back here

    • In the Cloud Manager, click one of the pictures you uploaded. That copies its link (nothing seems to happen, but it's copied).
    • Paste the link into the box below that has the same file name. A green bar means it worked.
    • Repeat for each picture.

    This page remembers the links. Next time, only pictures that changed need uploading and pasting again.

    The boxes for the links appear here after step 1.

  4. Download the TTS deck

    Use the button below, then follow “Put the deck into TTS”.

The deck looks for its pictures in this folder, so it has to be exact. Copy it from your file manager's address bar.

Where is it?

Windows: C:\Users\you\Documents\My Games\Tabletop Simulator\Saves\Saved Objects

Mac: /Users/you/Library/Tabletop Simulator/Saves/Saved Objects

Linux: /home/you/.local/share/Tabletop Simulator/Saves/Saved Objects

After downloading, you'll upload the pictures from the images folder to this address.

Put the deck into TTS

  1. Unzip the deck

    Inside is a folder called Card Builder. It holds your decks and an images folder with the card pictures.It holds your decks. The pictures stay in your Steam Cloud.

  2. Upload the pictures to your website

    Upload the files inside Card Builder/images to Check one: it should open in your browser at that address followed by its file name.

  3. Move the whole Card Builder folder into your Saved Objects folder

    It must go in exactly this folder, because that's where the deck looks for its pictures:

    That's TTS's own folder for saved objects:

    Windows: Documents\My Games\Tabletop Simulator\Saves\Saved Objects
    Mac: ~/Library/Tabletop Simulator/Saves/Saved Objects
    Linux: ~/.local/share/Tabletop Simulator/Saves/Saved Objects

    Afterwards, Saved Objects should contain Card Builder directly. If you see Card Builder inside another Card Builder, move the inner one up.

  4. Put a deck on the table

    In TTS, click Objects in the top menu, then Saved Objects, open the Card Builder folder, and click a deck.

    Everyone in your game sees the cards. Only the person putting the deck on the table needs the files.

    Only you will see these cards. To play with others, choose Steam Cloud above.

If something goes wrong
  • The deck isn't in Saved Objects. Check that Card Builder sits directly inside the Saved Objects folder, not inside another folder. In TTS, you may need to close and reopen the Saved Objects window.
  • The cards are blank or show an image error. TTS can't load a picture from its link. Check that each link was pasted next to the right file name, download the TTS deck again, and replace the old Card Builder folder. TTS can't find the pictures. The deck looks for them in exactly this folder, so check they're there: If they are and it still fails, use Steam Cloud instead: it doesn't depend on folders. TTS can't load the pictures. Check that they open in your browser at the address you entered.
  • There's no Upload menu. Some versions of TTS call it Modding. The Cloud Manager is in that menu.
  • You changed some cards. Do steps 1 to 4 again. Only pictures that changed need uploading and pasting; the rest fill in by themselves. Download the deck again. Download the deck again and upload the new pictures. Then replace the old Card Builder folder in Saved Objects. Changed pictures get new names, so TTS won't show old copies.

The deck ZIP also includes these steps in HOW TO IMPORT.txt.

Spreadsheet columns

The first row holds column names. Only name is needed; everything else is optional.

nameCard name.
countCopies in the deck (default 1; 0 leaves the card out).
deckWhich deck the card belongs to. Each deck becomes its own TTS object.
artOptional. Images match cards by name; use this to pick a different file, e.g. shared-art.png.
costShown in a badge in the corner (Street shows it as $3).
type, subtypeType line, e.g. “Creature — Imp”.
tagsStreet: tags shown after the type, all in one cell separated by commas, e.g. Crew, Leader.
textRules text. Supports **bold**, *italic*, {icon} and line breaks.
flavorItalic flavor text under the rules.
statsDefault, Full Art, Text Only: one badge, e.g. 3 / 2.
strengf, helf, stealStreet: the three Thug stats, each in its own box. Leave them empty on other cards and the rules box grows to fill the space.
colorOptional card color: a name (crimson) or hex (#3b5b7a). Street colors cards by type unless this is set.
layoutOverride the layout for this card: .

Icons: {fire} in text draws an uploaded image named fire.png or icon-fire.png. Without one, it draws a ringed letter.
