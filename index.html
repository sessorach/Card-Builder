A deck for each deck in your spreadsheet, with the right number of copies.

How will TTS get the card images?
  1. Download the images to upload. Unzip them anywhere, like your Downloads folder.
  2. Upload them in TTS. Start any game, open the Cloud Manager from the menu bar at the top (under Modding or Upload, depending on your TTS version), click the folder icon next to its search bar, and pick the images.
  3. Copy each link back here. Click an uploaded image in the Cloud Manager to copy its link, then paste it next to the same file name below.
  4. Download the TTS deck with the button below.
Where is it?

Windows: C:\Users\you\Documents\My Games\Tabletop Simulator\Saves\Saved Objects

Mac: /Users/you/Library/Tabletop Simulator/Saves/Saved Objects

Linux: /home/you/.local/share/Tabletop Simulator/Saves/Saved Objects

After downloading, upload the files from images/ to this address.

How to load your deck into TTS
  1. Follow steps 1–4 above to upload the images and download the TTS deck.
  2. Unzip the deck. Inside is a folder called Card Builder.
  3. Move the Card Builder folder into your TTS Saved Objects folder. Windows: Documents\My Games\Tabletop Simulator\Saves\Saved Objects
    Mac: ~/Library/Tabletop Simulator/Saves/Saved Objects
    Linux: ~/.local/share/Tabletop Simulator/Saves/Saved Objects
  4. Open TTS, click Objects in the top menu, then Saved Objects → Card Builder, and click a deck to put it on the table.

If something goes wrong

  • The deck isn't in Saved Objects: make sure Card Builder sits directly inside Saved Objects. Unzipping sometimes adds an extra folder around it; if so, move the inner one.
  • Cards are blank or show an image error: TTS can't find the pictures. Spreadsheet columns

The first row holds column names. Only name is needed; everything else is optional.

nameCard name.
countCopies in the deck (default 1; 0 leaves the card out).
deckWhich deck the card belongs to. Each deck becomes its own TTS object.
artOptional. Images match cards by name; use this to pick a different file, e.g. shared-art.png.
costShown in a badge in the corner (Street shows it as $3).
type, subtypeType line, e.g. “Creature — Imp”.
tagsStreet: tags shown after the type, all in one cell separated by commas, e.g. Crew, Leader.
textRules text. Supports **bold**, *italic*, {icon} and line breaks.
flavorItalic flavor text under the rules.
statsDefault, Full Art, Text Only: one badge, e.g. 3 / 2.
strengf, helf, stealStreet: the three Thug stats, each in its own box. Leave them empty on other cards and the rules box grows to fill the space.
colorOptional card color: a name (crimson) or hex (#3b5b7a). Street colors cards by type unless this is set.
layoutOverride the layout for this card: .

Icons: {fire} in text draws an uploaded image named fire.png or icon-fire.png. Without one, it draws a ringed letter.
